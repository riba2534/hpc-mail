数据库迁移为增量添加字段、通知/清理台账、临时对象租约和外部附件引用；升级不主动清理历史邮件，也不修改线上保留策略、域名列表和共享关系。迁移为旧外发附件补充剩余 90 天的对象引用，并清理同消息同对象的重复附件引用后添加唯一索引。

Cloudflare 的 Browser Integrity Check 会在 Worker 之前拒绝默认 Python urllib User-Agent。已准备 `scripts/configure-api-bic.mjs`，仅为 `/api/` 和 `/v1/` 关闭这一检查，保留其余安全规则。当前 Token 写入 WAF/Rulesets 和读取 Page Rules 被 403 拒绝；需要现有 Token 的对应区域编辑权限。此前采用明确 User-Agent 的客户端可正常访问。

验证边界：收发 MIME、Cloudflare EmailMessage 和通知服务的故障场景在本地 workerd 中模拟；生产验证读取实际网站、部署版本、数据库迁移和登录/邮箱/邮件详情/通知状态 API，不主动向真实外部邮箱或第三方通知端点发送测试消息。实际外部收件箱送达不由模拟测试证明。

本地最终验证：shared 25、web 103、worker 197，共 325 项正式测试通过；全仓类型检查、生产构建、依赖审计、OpenAPI recommended lint（无错误/警告）、Worker 部署预演通过。增量迁移在本地 workerd 重放后验证 20 张业务表，Drizzle 确认无遗漏的 schema 差异。生产部署与冒烟结果以本次 main 提交对应的 GitHub Actions 运行记录为准。
